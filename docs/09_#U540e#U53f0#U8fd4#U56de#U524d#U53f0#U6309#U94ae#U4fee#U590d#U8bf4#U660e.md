# 后台返回前台按钮修复说明

## 问题

管理员进入后台后，顶部按钮仍显示“进入后台”，点击后仍停留在后台，缺少返回前台的入口。

## 修复内容

修改文件：

- `frontend_api_demo/app.js`

修复逻辑：

1. 当当前页面是前台且用户为管理员时，顶部显示“进入后台”。
2. 当当前页面是后台且用户为管理员时，顶部显示“返回前台”。
3. 点击“返回前台”后：
   - 将路由切回 `home`
   - 清空当前测验状态
   - 重新读取数据
   - 渲染前台页面

## 生效方式

如果只替换了 `frontend_api_demo/app.js`，通常只需要重启 Caddy 或强制刷新浏览器：

```bat
docker restart enertri_caddy_local
```

然后浏览器按 `Ctrl + F5`。

如果仍不生效，请完整重建：

```bat
docker compose -f docker-compose.local.yml up -d --build --force-recreate
```
