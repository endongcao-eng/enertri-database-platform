# EnerTri V3 服务器部署说明

本版以“V2 中 `backend/requirements.txt` 已经固定 `bcrypt==4.0.1`”为前提升级，避免 passlib 与新版 bcrypt 的兼容报错。

## 1. V3 与 V2 的主要区别

- 前端默认 API 地址从 `http://127.0.0.1:8000/api` 改为 `/api`，适合线上同域部署。
- 新增 `backend/Dockerfile`。
- 新增生产版 `docker-compose.yml`：PostgreSQL + FastAPI + Caddy。
- 新增 `caddy/Caddyfile.example`：自动 HTTPS 与反向代理。
- 新增本地容器测试版 `docker-compose.local.yml`。
- 新增备份/恢复脚本 `scripts/backup.sh`、`scripts/restore_db.sh`。
- 后端 CORS 改为读取 `.env` 中的 `CORS_ORIGINS`，不再默认全开放。

## 2. 本地先用 Docker 测试

在项目根目录运行：

```bash
docker compose -f docker-compose.local.yml up -d --build
```

访问：

```text
http://127.0.0.1:8080
```

后端 API 文档：

```text
http://127.0.0.1:8080/api/docs
```

注意：如果 `/api/docs` 访问不到，也可以查看后端日志：

```bash
docker compose -f docker-compose.local.yml logs -f backend
```

## 3. 服务器部署准备

服务器建议：

- Ubuntu 22.04 / 24.04
- 2 核 2GB 以上，建议 4GB 内存
- Docker 与 Docker Compose 插件
- 一个已解析到服务器公网 IP 的域名

安装 Docker：

```bash
sudo apt update
sudo apt install docker.io docker-compose-plugin -y
sudo systemctl enable --now docker
```

## 4. 配置生产环境

### 4.1 修改数据库密码

打开根目录 `docker-compose.yml`，把两处：

```text
CHANGE_ME_STRONG_DB_PASSWORD
```

改成同一个强密码。

### 4.2 创建后端 `.env`

复制：

```bash
cp backend/.env.production.example backend/.env
```

然后修改：

```env
DATABASE_URL=postgresql+psycopg://enertri_user:你的数据库强密码@db:5432/enertri
SECRET_KEY=一串很长的随机密钥
CORS_ORIGINS=https://你的域名
```

生成随机密钥可用：

```bash
openssl rand -hex 32
```

### 4.3 配置 Caddy 域名

复制：

```bash
cp caddy/Caddyfile.example caddy/Caddyfile
```

把其中的：

```text
enertri.example.com
```

改成你的真实域名。

## 5. 启动网站

```bash
docker compose up -d --build
```

查看状态：

```bash
docker compose ps
```

查看日志：

```bash
docker compose logs -f backend
```

访问：

```text
https://你的域名
```

## 6. 初始化演示数据

后端启动时会自动创建表并写入默认分类、管理员和学生演示账号。如果你不希望正式环境保留演示账号，请上线后立即修改密码，或在代码中删除演示 seed 逻辑后重新部署。

默认演示账号仍是：

```text
管理员：admin / admin123
学生：student / 123456
```

正式部署后必须修改。

## 7. 导入 Excel 词条

容器运行后，可以执行：

```bash
docker compose exec backend python scripts/import_terms_from_excel.py /path/in/container/数据库词条填写模板.xlsx
```

更常用的方法是通过后台 API 的 Excel 上传导入接口，或先把 Excel 文件复制进容器：

```bash
docker cp 数据库词条填写模板.xlsx enertri_backend:/app/terms.xlsx
docker compose exec backend python scripts/import_terms_from_excel.py /app/terms.xlsx
```

## 8. 备份与恢复

备份数据库与上传文件：

```bash
./scripts/backup.sh
```

恢复数据库：

```bash
./scripts/restore_db.sh backups/enertri_YYYYMMDD_HHMMSS.sql
```

建议把 `backups/` 定期同步到服务器外部，例如对象存储或学校 NAS。

## 9. 常用维护命令

```bash
# 重启
 docker compose restart

# 停止
 docker compose down

# 更新后重新构建
 docker compose up -d --build

# 查看后端日志
 docker compose logs -f backend

# 查看 Caddy 日志
 docker compose logs -f caddy
```
