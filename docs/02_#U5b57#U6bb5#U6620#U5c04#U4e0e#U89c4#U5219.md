# Excel / Word / 数据库字段映射与校验规则

| Excel 列名 | 数据库/API 字段 | 校验规则 | 说明 |
|---|---|---|---|
| 中文术语 | `zh` | 必填 | 词条中文名 |
| 英文术语 | `en` | 必填 | 词条英文名 |
| 俄文术语（可选） | `ru` | 可空 | 保留三语展示能力 |
| 学术版术语解释 | `definition_zh_academic` | 必填，空值导入为“待补充” | 面向课程/数据库正式释义 |
| 通俗版术语解释 | `definition_zh_popular` | 可空，建议填写 | 面向公众号文章或科普展示 |
| 简要英文解释 | `definition_en` | 可空，建议填写 | 英文简明释义 |
| 关键词（3–5个，用逗号分隔） | `keywords[]` | 建议 3-5 个 | 自动拆分到 keywords / term_keywords |
| 相关术语 | `related_term_ids[]` | 后续建议做术语名匹配 | 当前前端支持 ID 录入 |
| 应用场景 | `application_scenario` | 可空，建议填写 | 用于学习页和案例说明 |
| 公式 / 模型（如有） | `formula_model` | 可空 | 可存 LaTeX、纯文本或模型名 |
| 有无视频形式的示例或工程案例 | `has_video`, `video_path` | 有/无 | “有”时先填“待上传” |
| 参考文献（1–2篇） | `references[]` | 建议 1-2 条 | 拆分到 term_references |
| 填写本词条的学生姓名 | `contributor_name` | 可空 | 关联 contributors |
| 填写本词条的学生研究方向 | `contributor_research_direction` | 可空 | 关联 contributors |
| 审核状态 | `review_status` | draft/submitted/approved | 学生不填也可以，导入默认 draft |

## 审核流

```text
学生/导入创建 draft → 提交 submitted → 管理员审核 approved → 前台展示
```

## 正式化建议

1. 课程作业收集阶段：统一导入为 `submitted`，管理员集中审核。
2. 词条打磨阶段：管理员把不合格条目改回 `draft`，并写 `review_comment`。
3. 平台公开展示：只查询 `approved`。
