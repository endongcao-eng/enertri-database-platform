# V4.7.0-webprep.22 论文科研价值增强

本版本把论文库从“能解析”推进到“可核验、可纠错、可评测”：

- `knowledge_tables` 保存 PDF 页坐标 `bbox_json`、提取策略、0–1 置信度、裁剪图路径与人工修正记录。
- 论文详情返回表格裁剪预览和图片预览 URL；接口会检查登录身份和存储根目录，前端以授权 Blob 方式显示。
- 表格卡片支持人工改标题、页码、bbox、二维数据；保存后可按新 bbox 重裁剪。
- 问答采用全文词项匹配 + 本地向量的混合分数。低于 `PAPER_EVIDENCE_MIN_SCORE`（默认 0.22）或证据过于接近时，明确返回“无法确定”。
- 空间能源主库记录可以通过 `POST /api/literature/publications/{id}/save` 一键保存到当前用户个人知识库；这是元数据记录，不会假装已经拥有全文 PDF。
- `backend/tests/fixtures/energy_relevance_eval.json` 是能源动力相关性标注集，包含 NASA 空间太阳能真实公开来源以及此前出现的杭州茶文化误召回案例。
- `backend/tests/fixtures/paper_corpus/manifest.json` 覆盖四表格、双栏、英文扫描、中文扫描，并保留公开来源锚点；受版权保护的论文二进制由部署者按许可挂载，不进 Git。

升级数据库时沿用现有启动流程，Alembic 会从 `v4_7_operational_health` 升级到 `v4_7_literature_research_value`。Railway Volume 仍必须挂载到 `/data`，否则裁剪图和原始 PDF 都无法持久化。
