# V4.7 HTML 视频与科普库

## 使用方式

管理员在管理后台的“HTML 视频与科普库”区域上传 `.html` 文件，一次最多 10 个。文件名直接决定关联关系：

- `离心泵.html`：关联“离心泵”术语，显示在“视频学习”模块。
- `离心泵科普.html`：关联“离心泵”术语，显示为“科普文章”。

平台会按术语的中文、英文或俄文名称进行精确匹配，并将匹配结果写入数据库。术语详情页不再扫描 HTML 文件目录，而是读取数据库中的关联状态和资源地址。

## 前台显示

- 有对应视频 HTML 时，视频学习区域显示蓝色播放按钮，点击后在新标签页打开 HTML 内容。
- 没有对应视频 HTML 时显示“无对应视频”。旧版 MP4 视频仍可继续播放。
- 有对应科普 HTML 时，专题科普区域显示“科普文章”按钮；没有时显示“无对应文章”。

HTML 内容以沙盒策略返回，禁止上传页面中的脚本访问平台登录信息。
