# V4.7.0-webprep.23 表格正文误识别修复

## 问题表现

部分期刊 PDF（尤其是双栏、无边框表格的版式）使用“按文字间距推断表格”时，会把整页正文拆成许多单元格。旧结果因此可能显示为每页一个巨大表格，表格标题、作者、期刊页眉和正文都被混入其中。

## 修复内容

- 文本型表格候选必须同时满足表题、数值信号或紧凑多列证据之一。
- 增加“字符碎片化网格”拦截：当双栏正文被拆成大量一至两个字符的单元格、且没有真实表题时直接拒绝。
- 对覆盖几乎整页且没有数值/紧凑网格特征的候选继续拒绝。
- 每页表格诊断保存接受数、拒绝数、策略和拒绝原因，便于复核。
- 旧版本没有 `bbox`、策略和置信度的 PDF 表格记录不会再渲染成表格卡片；详情页会提示重新解析。重新解析成功后，解析结果和裁剪图目录一次性替换，失败则保留旧结果。
- 保留有线框/几何证据的表格策略，因此四表格、多栏、扫描和中文 OCR 测试集仍可覆盖。

## 对 Applied Energy 292 (2021) 116896 的操作

部署本版本后，打开原文档详情并点击“重新解析”。等待任务变为 `ready` 后，检查：

1. 表格数量不再等于页数，正文页不会生成巨大表格卡片。
2. 真正的表格显示页码、`bbox`、提取策略、置信度和裁剪预览。
3. 表格卡片中的“人工修正”可修改标题、页码、bbox 和二维数据；保存 bbox 后会重裁剪原 PDF。
4. 若新解析失败，页面显示失败状态，但不会留下半套新结构化结果。

本版本不删除原始论文文件，也不需要新的数据库迁移；Railway Volume 仍应挂载到 `/data`。
