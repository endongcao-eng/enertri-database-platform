# V4.7 术语批量管理

## 功能

管理员进入“术语库管理”后，可以在分页术语表左侧勾选术语。搜索关键词、审核状态或主题后，列表只显示当前筛选结果；“全选当前页”只勾选当前页面实际显示的术语，不会把其他分页或隐藏结果误加入批量操作。

批量操作包括：

- 批量通过：将选中术语的审核状态改为 `approved`，并记录“审核通过”。
- 批量删除：删除选中的术语；前端要求二次确认，后端要求管理员权限。

切换关键词、状态、主题筛选或分页时，选择会自动清空，避免把上一组筛选结果带入下一组操作。单条“通过”和“删除”入口继续保留。

## 接口

- `POST /api/terms/bulk/review`，请求体：`{"term_ids": [1, 2]}`；需要 `process.approve` 权限。
- `POST /api/terms/bulk/delete`，请求体：`{"term_ids": [1, 2]}`；需要管理员权限。

接口会去重 ID；全部 ID 不存在时返回 404。批量删除沿用术语实体的数据库级联关系。
