# V4.7 空间能源论文主库联动

## 数据职责

- 空间能源平台是论文目录的权威主库。
- EnerTri 通过后端实时访问空间能源平台的论文列表、详情和全文检索接口。
- `space_energy_literatures` 是 EnerTri PostgreSQL 中按主库 `literatures` 字段结构建立的读穿镜像，只在上游读取成功后写入；论文目录接口不从该镜像回退读取。
- EnerTri 用户上传的 PDF/DOCX、结构化页、表格和证据继续保存在 EnerTri 知识库。
- EnerTri 原来的 OpenAlex / Crossref 元数据记录继续供科研成长计划等既有外部来源功能使用，不作为主库离线回退。

## 运行配置

设置：

```env
SPACE_ENERGY_API_BASE_URL=https://114514191981061285174648.dpdns.org
SPACE_ENERGY_TIMEOUT_SECONDS=8
SPACE_ENERGY_API_TOKEN=
```

`SPACE_ENERGY_API_BASE_URL` 是空间能源平台后端的 HTTPS 根地址，不带 `/api` 后缀。只读接口目前可匿名访问；如果上游部署增加服务端鉴权，再在 `SPACE_ENERGY_API_TOKEN` 设置服务凭证。凭证只由 EnerTri 后端读取。

## 可用接口

- `GET /api/literatures`：分页及题名/摘要关键词检索。
- `GET /api/literatures/{id}`：论文详情。
- `GET /api/search`：上游全文检索，EnerTri 多来源检索器使用。
- `GET /api/literature/central/status`：登录用户查看主库连接状态。

空间能源平台不可用时，EnerTri 主库目录 API 返回 HTTP 503；前端清空当前主库结果，并每 15 秒复查连接状态。在线后重新加载当前页。OpenAlex、Crossref 作为显式勾选的补充检索来源，不会伪装成主库数据。

## 文件与全文边界

上游数据库包含 `full_text` 与 `source_file` 字段，但其现有论文 REST 响应未返回这两个字段，也没有随代码包提供 PDF 附件。因此联动页面显示上游 API 实际返回的书目元数据、摘要、DOI 和论文链接；已上传到 EnerTri 知识库的 PDF/DOCX 仍可继续进行逐页解析和证据问答。

## 数据库升级

Alembic revision `v4_7_space_energy_literature` 新增兼容表和索引。Railway 部署继续由既有 `init` 服务升级数据库；更新后需确认 readiness 返回新 revision，并在 EnerTri 登录后打开“文献与论文知识系统”检查主库连接状态、分页、搜索以及主库离线状态。
