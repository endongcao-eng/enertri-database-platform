# Excel 导入分类

管理后台的“Excel 批量导入”现在支持在提交前填写分类名称。

## 使用方式

1. 以管理员账号进入管理后台。
2. 在“Excel 批量导入”区域选择 `.xlsx` 文件。
3. 在“分类”输入框填写分类名称，例如“航空热防护”。
4. 点击“导入 Excel”。

分类名称按可见名称复用，忽略首尾空格和大小写差异；不存在时自动创建。分类留空时使用“未分类”。

本次工作簿中的新词条会直接写入该分类。已存在的相同中文术语和英文术语不会重复创建，但会移动到本次选择的分类下，并在结果中计入“已归类”。

工作簿仍需包含“中文术语”和“英文术语”两列；“关联词汇”与“关键词（3–5个，用逗号分隔）”均可用于关键词，其他模板列按原有规则导入。
