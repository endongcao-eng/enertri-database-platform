## 3. 统一任务中心

状态机：

```text
queued → running → succeeded
                 ↘ failed
queued/running → cancelled
failed/cancelled/succeeded → retry(new task)
```

任务主表记录输入、结果、进度、步骤、错误、起止时间、重试来源、模型版本和软件版本。`task_events` 保存每次状态/进度事件，前端轮询 `/api/tasks` 和 `/api/tasks/{id}` 展示变化。

已接入任务类型：

- `paper_analysis`
- `ppt_generation`
- `video_analysis`
- `simulation_package`

论文解析实测进度：0（排队）→ 3（执行器接管）→ 12（文件校验）→ 35（内容提取）→ 58（保密策略/本地解析）→ 86（整理结果）→ 100（成功）。

## 4. 文件治理

统一文件库的核心策略：

- 上传前检查大小和后缀白名单。
- 计算 SHA-256，同一用户重复内容直接复用原记录。
- 物理文件使用 UUID 随机名，不使用原始文件名作为路径。
- 按年月目录存放，生成成果也登记到同一文件库。
- 文件访问基于归属和 `file.other.view` 权限。
- `restricted` 文件无论前端传入何值，`external_ai_allowed` 都强制为 `false`。
- `expires_at` 到期文件可由启动清理或管理员清理接口删除。
