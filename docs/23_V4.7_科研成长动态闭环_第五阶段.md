# V4.7 科研成长动态闭环

## 为什么要有第五阶段

V4.6 已经能给出“应该学什么”，但真正用于教学管理还需要知道“建议有没有执行、执行后有没有形成证据、证据是否被老师认可、画像是否真的变化”。因此 V4.7 增加执行与回流层。

## 闭环

```text
发展目标
→ 五类统一路线（课程 / 专业书 / 论文 / 科研实践 / 项目）
→ 计划中 / 进行中 / 已完成
→ 标准资源完成后生成待核验证据
→ 导师核验
→ 个人科研画像重算
→ 目标匹配快照
→ 下一轮路线
```

## 可信度规则

“用户点击完成”只能说明路线项已完成，不能自动证明科研能力。V4.7 自动创建的待核验证据在未核验阶段采用较低可信权重；教师核验时仍可补充导师评分、成果质量和核验意见。这样可以让系统即时展示临时变化，又不会把自报完成等同于高可信科研能力。

## 论文与项目

论文推荐优先从系统内部 `publications` 和论文知识库匹配；演示环境中的示例条目明确标注为内部演示文献，不作为真实外部文献事实。实际最新论文继续通过 V4.2 文献检索 Provider 获取。

科研项目则从系统已有 `research_projects` 中按目标方向和知识缺口匹配，作为把知识转化为可验证科研证据的实践载体。
