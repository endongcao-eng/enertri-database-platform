# V4.7 HTML 科普页面包库

## 使用场景

没有外部资源的单页内容可以继续上传单个 HTML。包含 `index.html`、其他 HTML 页面、CSS、JavaScript、图片或音频的科普内容，应当作为 ZIP 页面包上传。

## ZIP 结构

一个 ZIP 可以包含多个页面文件夹。每个包含 `index.html` 的文件夹会被识别为一个页面包：

```text
11.13科普视频.zip
├─ 1_AI辅助气动热环境流场反演/
│  ├─ index.html
│  ├─ term-01.html
│  └─ assets/
├─ 2-TPMS复杂冷却结构/
│  ├─ index.html
│  └─ assets/
└─ 3-超燃热防护科普/
   ├─ index.html
   └─ assets/
```

上传时平台会保留目录关系，并将入口暴露为：

```text
/api/html-library/{页面包编号}/bundle/index.html
```

因此 `index.html` 中的 `term-01.html`、`assets/style.css`、`assets/app.js` 等相对路径可以继续工作。

## 术语自动匹配

平台会去掉文件夹名称开头的序号和末尾的“科普”再匹配中文、英文或俄文术语。例如：

```text
3-超燃热防护科普 → 超燃热防护
8.热防护涂层科普 → 热防护涂层
```

匹配成功后，术语的 `html_article_available` 会被设置为真，并在“专题科普”模块显示“科普文章”。

## 安全限制

- ZIP 必须包含 `index.html`；
- 禁止绝对路径、`..` 路径和符号链接；
- 默认 ZIP 压缩包不超过 128 MB，解压后不超过 512 MB；
- 每个 ZIP 最多 10 个页面包；
- 页面资源只能在各自页面包目录内访问。
