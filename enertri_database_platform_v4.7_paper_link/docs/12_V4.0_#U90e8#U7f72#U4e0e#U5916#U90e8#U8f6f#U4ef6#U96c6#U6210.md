# V4.0 部署与外部软件集成

## 1. 配置文件

复制：

```text
backend/.env.example → backend/.env
```

生产部署使用 `backend/.env.production.example` 作为起点，不能原样上线。

## 2. AI 配置

```env
OPENAI_API_KEY=
OPENAI_MODEL=gpt-5.1
OPENAI_BASE_URL=https://api.openai.com/v1
AI_REQUEST_TIMEOUT_SECONDS=180
```

密钥只存放在后端环境变量中，前端无法读取。未配置密钥时，调用论文阅读、学术写作、图像分析和 AI 多模态接口会返回 503；规则型能力正常工作。

## 3. 文献服务配置

```env
OPENALEX_API_KEY=
LITERATURE_CONTACT_EMAIL=research@example.com
LITERATURE_TIMEOUT_SECONDS=30
```

OpenAlex 当前要求 API Key，建议在生产环境配置免费 Key。Crossref 是基础检索回退；没有 Key 或 OpenAlex 不可用时，热点模块使用带样本量和限制说明的 Crossref 样本统计，不会伪装成 OpenAlex 全库聚合。

## 4. 文件目录

```env
MEDIA_DIR=/app/media
ARTIFACT_DIR=/app/media/artifacts
WORKSPACE_DIR=/app/media/workspace
WORKSPACE_MAX_FILE_MB=30
WORKSPACE_MAX_FILES=8
```

Docker Compose 将宿主机 `uploads` 挂载到 `/app/media`。生成的 Word、PPT、仿真输入包和运行日志均需要纳入备份策略。

## 5. 外部仿真软件

默认：

```env
SIMULATION_EXECUTION_ENABLED=false
```

只有服务器满足以下条件后才能开启：

- 已合法安装对应软件和版本
- 许可证服务器可访问
- 批处理命令已经过管理员手工验证
- 运行账户只具备所需最小权限
- 工作目录、磁盘配额、并发数和超时受控
- 输入模板经过 CAE 工程师审查

命令变量：

```env
SIM_HYPERMESH_COMMAND=
SIM_ANSYS_MAPDL_COMMAND=
SIM_ANSYS_FLUENT_COMMAND=
SIM_MARC_COMMAND=
SIM_FLOW3D_COMMAND=
```

模板支持：

```text
{input}   当前任务主输入文件
{workdir} 当前任务目录
{job_id}  平台任务 ID
```

示意配置：

```env
SIM_ANSYS_MAPDL_COMMAND=/opt/ansys/bin/mapdl -b -i {input} -o {workdir}/mapdl.out
```

命令参数随软件版本、操作系统和许可证环境变化，上述只展示占位符用法，部署前必须按本机官方文档验证。

## 6. 工业实时接入

V4.0 提供 HTTP 批量数据入口，但不内置所有厂商的 PLC、OPC UA、Modbus、MQTT 或焊机私有协议驱动。建议部署边缘采集网关负责：

1. 协议适配
2. 采样与缓存
3. 时间同步
4. 单位统一
5. 设备和工件 ID 绑定
6. 断网重传
7. 传感器健康检查
8. 分批调用 `/api/workspace/telemetry/ingest`

更高频或低延迟闭环控制不能通过本平台的普通 HTTP 分析接口直接实现，应由经过功能安全评估的现场控制系统承担。

## 7. 数据安全

- 不在前端保存 AI 或文献 API 密钥。
- 对外部 AI 服务发送论文或生产数据前，确认授权、保密和跨境数据要求。
- 对上传文件配置反向代理大小限制、访问日志、备份和恶意文件扫描。
- 生产环境关闭默认演示账号或强制改密。
- 商业软件运行节点建议与公网服务隔离，并通过受控队列或专用执行节点连接。
