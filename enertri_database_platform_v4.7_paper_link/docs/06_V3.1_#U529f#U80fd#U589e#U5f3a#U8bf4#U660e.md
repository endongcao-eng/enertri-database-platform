# V3.1 功能增强说明

本次增强目标是：在不大改原有 FastAPI + PostgreSQL + 静态前端架构的前提下，把“能源三语术语库”升级为更像科普学习平台的版本。

## 新增功能

### 1. 专题科普文章

新增 `articles` 表与接口，可存储面向公众的科普文章。前端首页右侧会展示与当前词条相关的文章，并通过关键词联动术语检索。

接口：

- `GET /api/articles`
- `GET /api/articles/{id}`
- `POST /api/articles`，管理员权限
- `PUT /api/articles/{id}`，管理员权限
- `DELETE /api/articles/{id}`，管理员权限

### 2. 收藏夹

新增用户术语学习状态表 `user_term_progress`。登录用户可以把重要术语加入收藏夹，首页右侧显示收藏列表。

接口：

- `GET /api/me/progress`
- `POST /api/me/progress/{term_id}`

### 3. 学习进度

登录用户可以把术语标记为“已学”。前端会显示进度条、已学数量，以及术语列表中的已学标记。

### 4. 随堂测验

新增基于词条内容自动生成入门题的接口。每个词条会生成 3 道题：英文术语、通俗解释、关键词关联。登录用户提交后会保存最高分。

接口：

- `GET /api/terms/{term_id}/quiz`
- `POST /api/terms/{term_id}/quiz/submit`

### 5. 前端体验优化

- 首页文案升级为“进阶版能源科普平台”。
- 增加专题文章、我的学习、随堂测验三个区块。
- 词条详情页增加收藏、已学按钮。
- 修复视频路径写死 `127.0.0.1:8000` 的问题，改为使用同域 `/media/...`。
- 管理后台增加“新增能力”提示区，保留原有词条管理流程。

## 新增默认演示数据

启动后会自动创建两篇专题文章：

1. 为什么光伏板能把阳光变成电？
2. 碳中和离普通人有多远？

## 数据库说明

本版本新增两张表：

- `articles`
- `user_term_progress`

开发环境仍可通过 `Base.metadata.create_all()` 自动建表；正式 PostgreSQL 可参考 `database/schema.sql` 中新增 SQL。

## 后续建议

本次增强故意保持轻量。下一步可以继续扩展：

1. 专题文章后台编辑页面。
2. 题库管理与人工出题。
3. 术语知识图谱可视化。
4. MathJax / KaTeX 公式渲染。
5. AI 辅助解释、出题和审核。
