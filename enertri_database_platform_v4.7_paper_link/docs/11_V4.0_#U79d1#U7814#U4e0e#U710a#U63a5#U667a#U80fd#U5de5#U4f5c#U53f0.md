# V4.0 科研与焊接智能工作台

## 1. 功能入口

用户登录后，顶部出现“智能工作台”。工作台分为：

1. 科研助手
2. 生产助手
3. 图像与多模态
4. 仿真集成

所有任务写入 `assistant_jobs` 或 `simulation_jobs`，保留输入摘要、输出、时间和生成文件索引。

## 2. 科研助手

### 2.1 全球文献检索

接口：

```http
POST /api/workspace/literature/search
```

可指定检索词、年份、语言、开放获取和结果数量。配置 OpenAlex API Key 后使用 OpenAlex；未配置 Key 或服务故障时，基础文献检索回退到 Crossref。

平台只提供元数据、摘要（数据源提供时）、DOI、落地页和合法开放获取地址。全文阅读需要用户上传自己有权访问的文献文件。

### 2.2 研究热点

接口：

```http
POST /api/workspace/literature/hotspots
```

配置 OpenAlex API Key 时，通过最近窗口和对照窗口的 OpenAlex 主题发文数量计算增长率和动量。没有 Key 或 OpenAlex 暂不可用时，系统基于 Crossref 返回样本中的学科标签/题名高频词生成回退统计，并同时显示样本量和限制说明。两种结果都只用于发现选题线索，不能单独证明研究价值或科学性。

### 2.3 论文结构化阅读

接口：

```http
POST /api/workspace/papers/analyze
```

输出：

- 文献信息
- 核心思想
- 试验材料/研究对象
- 研究方法与参数
- 核心数据
- 核心结论
- 创新点
- 局限性与复现风险
- 建议复核的原文位置

系统提示词强制区分原文事实、推断和无法确认的信息，不允许补造数据。

### 2.4 同行评审

接口：

```http
POST /api/workspace/papers/review
```

系统先检索相关文献元数据，再结合论文文件给出贡献、原创性、方法、统计、图表、证据支持、复现性和推荐意见。检索到的元数据不等同于已阅读相关全文，因此评审仍需专家复核。

### 2.5 学术写作与文件导出

接口：

```http
POST /api/workspace/writing/generate
```

支持 `literature_review`、`academic_report`、`grant_proposal`、`academic_ppt` 和 `production_report`。输出格式支持 Markdown、DOCX 和 PPTX。

## 3. 生产助手

接口统一接收材料体系、牌号、化学成分、厚度、接头、位置、工艺、氢水平、服役条件和现场现象。

- `/welding/weldability`：焊接性和潜在接头性能
- `/welding/elements`：合金元素作用
- `/welding/process`：初步工艺窗口
- `/welding/filler`：候选焊材
- `/welding/defect`：缺陷根因与措施

碳钢/低合金钢可计算：

```text
CE(IIW) = C + Mn/6 + (Cr+Mo+V)/5 + (Ni+Cu)/15
Pcm = C + Si/30 + (Mn+Cu+Cr)/20 + Ni/60 + Mo/15 + V/10 + 5B
```

计算值只是风险筛选指标。预热、层间温度、热输入、后热和焊后热处理必须结合适用标准、材料证书、拘束、氢水平和试验确定。

## 4. 图像与多模态

### 4.1 材料表征与 NDT

接口：

```http
POST /api/workspace/images/analyze
```

支持 SEM、TEM、EBSD、EDS、光谱、拉曼、X 射线探伤、超声波形和熔池图像。系统要求在缺少标尺、图例、原始数据、校准和采集条件时明确限制。

### 4.2 多模态融合

接口：

```http
POST /api/workspace/multimodal/analyze
```

可以同时上传图纸、文本、表格、图像、PDF 和视频。视频最多抽取若干关键帧。输出包括数据源识别、对齐假设、特征参数、异常事件、缺陷证据链、质量置信度和复核建议。

### 4.3 时序数据接入

接口：

```http
POST /api/workspace/telemetry/ingest
```

支持每批 2–20000 个采样点。采样点可以直接包含数值通道，也可放在 `values` 字段。建议通道名：

- `current_a`
- `voltage_v`
- `travel_speed_mm_s`
- `wire_feed_m_min`
- `temperature_c`
- `acoustic_rms`
- `pool_width_mm`

系统提取描述统计、RMS、变异系数、三西格玛异常、采样率、持续时间和热输入估计。质量分数是通用稳定性规则，不是合格证据。

## 5. 仿真集成

创建任务：

```http
POST /api/workspace/simulations
```

下载输入包：

```http
GET /api/workspace/simulations/{id}/download
```

管理员在执行开关和命令均配置后可启动：

```http
POST /api/workspace/simulations/{id}/run
```

平台使用独立进程执行预配置命令，不使用 shell 字符串拼接。生成模板必须由 CAE 工程师针对几何、材料、热源、相变、接触和边界条件补全。
