# EnerTri 数据库平台：按顺序实施说明

本版已按你提出的顺序把“数据库化、Excel 导入、API 启动、前端 API 化、后台审核”串成一条可运行链路。

## 1. 建库

开发阶段推荐先用 SQLite，后端首次启动会自动建表并生成 `backend/enertri.db`。

```bash
cd backend
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python scripts/seed_demo.py
```

正式部署可使用 PostgreSQL：

```bash
docker compose up -d db
# 然后把 backend/.env 中 DATABASE_URL 改成：
# postgresql+psycopg://enertri:enertri123@localhost:5432/enertri
```

## 2. 导入 Excel

```bash
cd backend
python scripts/import_terms_from_excel.py ../../数据库词条填写模板.xlsx --status submitted --skip-duplicates
```

导入逻辑：

- 中文术语、英文术语缺一不可。
- 俄文术语可为空。
- 关键词会按中英文逗号、中文分号、英文分号拆分。
- 参考文献会拆成多条记录。
- “有无视频形式的示例或工程案例”为“有”时，会先写入 `video_path=待上传`，之后可在后台替换。
- 默认导入到 `DEFAULT/未分类`，可以用 `--category-code PV --category-name 光伏` 改变导入分类。

## 3. 启动 API

```bash
cd backend
uvicorn app.main:app --reload
```

打开 API 文档：

```text
http://127.0.0.1:8000/docs
```

演示账号：

| 角色 | 用户名 | 密码 |
|---|---|---|
| 管理员 | admin | admin123 |
| 学生 | student | 123456 |

## 4. 前端读取 API

进入 `frontend_api_demo/`，用任意静态服务器打开：

```bash
cd frontend_api_demo
python -m http.server 5500
```

浏览器访问：

```text
http://127.0.0.1:5500
```

前端默认连接：

```javascript
http://127.0.0.1:8000/api
```

如需改地址，可在浏览器控制台或 HTML 前置脚本里设置：

```javascript
window.API_BASE = 'https://your-domain.example/api';
```

## 5. 后台写入、提交与审核

本版已包含：

- 登录：`/api/auth/login`
- 词条列表：`GET /api/terms?status=all`
- 新增词条：`POST /api/terms`
- 编辑词条：`PUT /api/terms/{id}`
- 学生提交：`POST /api/terms/{id}/submit`
- 管理员审核：`POST /api/terms/{id}/review`
- 删除词条：`DELETE /api/terms/{id}`
- 视频上传：`POST /api/media/videos`
- Excel 上传导入：`POST /api/import/excel`

前台普通浏览默认只显示 `approved` 词条，管理员后台可查看 `all/draft/submitted/approved`。
