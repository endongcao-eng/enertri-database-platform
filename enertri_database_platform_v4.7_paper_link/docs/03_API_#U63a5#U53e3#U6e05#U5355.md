# API 接口清单

## 认证

```http
POST /api/auth/login
GET  /api/auth/me
```

登录请求：

```json
{"username":"admin","password":"admin123"}
```

返回 `access_token`，前端后续请求使用：

```http
Authorization: Bearer <token>
```

## 分类

```http
GET  /api/categories
POST /api/categories       # 管理员
```

## 术语

```http
GET    /api/terms?status=approved&q=逆变器&category_id=1
GET    /api/terms/{id}
POST   /api/terms          # 登录用户
PUT    /api/terms/{id}     # 管理员或本人 draft
DELETE /api/terms/{id}     # 管理员
```

## 审核

```http
POST /api/terms/{id}/submit
POST /api/terms/{id}/review   # 管理员
```

审核请求：

```json
{"review_status":"approved","review_comment":"审核通过"}
```

## 导入与媒体

```http
POST /api/import/excel      # 管理员，multipart 上传 xlsx
POST /api/media/videos      # 登录用户，multipart 上传视频
```

## V3.1 新增接口

### 专题科普文章

- `GET /api/articles?status=approved&q=光伏`：文章列表。
- `GET /api/articles/{id}`：文章详情。
- `POST /api/articles`：新增文章，管理员权限。
- `PUT /api/articles/{id}`：更新文章，管理员权限。
- `DELETE /api/articles/{id}`：删除文章，管理员权限。

文章字段包括：`title`、`summary`、`content`、`difficulty`、`status`、`cover_label`、`related_keywords`。

### 我的学习进度

- `GET /api/me/progress`：获取当前用户所有术语学习记录。
- `POST /api/me/progress/{term_id}`：更新收藏、已学或备注。测验分数只能由测验提交接口写入。

请求示例：

```json
{
  "is_favorite": true,
  "learned": true,
  "note": "重点复习公式部分"
}
```

### 随堂测验

- `GET /api/terms/{term_id}/quiz`：根据词条自动生成 3 道入门题。
- `POST /api/terms/{term_id}/quiz/submit`：服务端判题；游客可提交，登录用户会保存最高分。

请求示例：

```json
{
  "quiz_token": "GET 题目接口返回的一次性令牌",
  "answers": {
    "q1": "A",
    "q2": "B",
    "q3": "A"
  }
}
```


## V3.2 访问控制说明

- `GET /api/terms?status=all`、`draft`、`submitted` 仅管理员可用；游客和普通用户只能批量读取 `approved`。
- 未发布词条详情仅管理员或词条创建者可读取。
- 未发布文章列表和详情仅管理员可读取。
- `GET /api/terms/{id}/quiz` 不返回答案或解析；判题后才通过提交接口返回。
